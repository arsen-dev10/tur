# Информационный туристический веб-сайт «Visit Kyrgyzstan»

## 1. Тема проекта

Разработка информационного веб-сайта для туристов по Кыргызстану с интерактивной картой, каталогом достопримечательностей, маршрутами, отзывами и административной панелью.

## 2. Актуальность

Кыргызстан обладает большим туристическим потенциалом: горы, озёра, ущелья, национальные парки и культурные объекты. Туристу сложно быстро найти проверенную информацию о местах, маршрутах и расположении объектов. Сайт объединяет эти сведения в одном понятном интерфейсе и помогает спланировать поездку.

## 3. Цель и задачи

**Цель:** создать удобный адаптивный сайт-путеводитель по Кыргызстану.

Для достижения цели были поставлены задачи:

1. Создать главную страницу с краткой информацией о стране.
2. Разместить каталоги мест, гор и туристических маршрутов.
3. Реализовать интерактивную карту объектов.
4. Добавить переключение языков: русский, кыргызский и английский.
5. Реализовать поиск, фильтрацию и раздел отзывов.
6. Создать административную панель для управления содержимым.
7. Перенести проект на React и настроить сборку через Vite.

## 4. Пользователи системы

| Пользователь | Возможности |
|---|---|
| Турист | Просматривает места, горы, маршруты, карту и отзывы; выбирает язык; использует поиск и фильтры. |
| Администратор | Входит в панель управления, добавляет и изменяет места и маршруты, работает с отзывами и настройками. |

## 5. Основные возможности сайта

- Главная страница с краткой презентацией Кыргызстана.
- Разделы «Места», «Горы», «Маршруты», «Карта» и «Отзывы».
- Интерактивная карта с маркерами туристических объектов.
- Поиск по туристическим объектам.
- Фильтрация мест и маршрутов по категориям.
- Перевод интерфейса на RU, KG и EN.
- Сохранение отзывов, настроек и данных админки в `localStorage` браузера.
- Вход в административную панель с главной страницы.
- Адаптивный интерфейс для телефона, планшета и компьютера.

## 7. Структура React-проекта

```text
проект/
├── public/                     # robots.txt и sitemap.xml
├── src/
│   ├── main.jsx                # React-точка входа и маршрутизация страниц
│   ├── styles/                 # Основные стили сайта и админ-панели
│   └── legacy/                 # Перенесённые страницы, переводы и логика
│       ├── public/             # Главная, места, горы, маршруты, карта, отзывы
│       └── admin/              # Вход, дашборд, места, маршруты, отзывы, настройки
├── index.html                  # HTML-точка Vite
├── package.json                # Команды и зависимости
└── vite.config.js              # Конфигурация Vite
```

React-приложение выбирает нужную страницу по параметру URL. Это позволяет открывать разделы без отдельных HTML-файлов:

- `?page=places` — места;
- `?page=mountains` — горы;
- `?page=routes` — маршруты;
- `?page=map` — карта;
- `?page=reviews` — отзывы;
- `?admin=` — вход в административную панель;
- `?admin=dashboard` — главная страница админки.

## 8. Как работает карта

На карте отображаются координаты туристических объектов: Иссык-Куль, Ала-Арча, Сон-Куль, Ош, Арсланбоб, каньон Сказка и другие. Для каждого объекта указываются название, категория, краткое описание и ссылка на соответствующий раздел сайта. Пользователь может отфильтровать объекты по типу: горы, озёра, культура или природа.

В приложенном фрагменте кода показан React-подход с библиотекой `react-leaflet`:

- `useState` хранит выбранный язык;
- массив `places` хранит названия, описания и координаты;
- `MapContainer` создаёт карту;
- `TileLayer` подключает слой OpenStreetMap;
- `Marker` и `Popup` выводят метки и информацию о месте.

Такой подход удобен тем, что новые места можно добавлять одной записью в массив `places`.

## 9. Как работает мультиязычность

Для каждого языка есть словарь переводов. Когда пользователь нажимает кнопку RU, KG или EN, приложение получает нужный объект переводов и заменяет тексты интерфейса. Данные туристических объектов также содержат название и описание на трёх языках.

Пример идеи:

```js
const [language, setLanguage] = useState('ru');
const t = translations[language];
```

`language` — текущий язык, а `t` — набор текстов на выбранном языке.

## 10. Административная панель

В шапке главной страницы находится кнопка «Админка». После входа администратор может открыть дашборд и разделы управления местами, маршрутами, отзывами и настройками.

Для демонстрационной версии используются данные:

```text
Логин: admin
Пароль: admin123
```

Сеанс входа действует 8 часов. Важно: эта авторизация является демонстрационной, потому что пароль хранится на стороне браузера. Для настоящего сайта необходимо подключить сервер, базу данных, безопасное хеширование паролей и роли пользователей.

## 11. Запуск проекта

Установить зависимости (выполняется один раз):

```powershell
npm install
```

Запустить проект в режиме разработки:

```powershell
npm run dev
```

После запуска открыть адрес из консоли, обычно `http://localhost:5173`.

Создать готовую версию для публикации:

```powershell
npm run build
```

Готовые файлы появляются в папке `dist`. Именно её содержимое загружается на хостинг.

## 12. Результат

В результате создан туристический информационный сайт о Кыргызстане. Он содержит основные сведения о достопримечательностях, горах и маршрутах, поддерживает три языка, имеет интерактивную карту, поиск, фильтрацию, отзывы и административную панель. Проект перенесён на React и собирается с помощью Vite.
